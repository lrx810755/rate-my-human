The one-line review an AI agent would leave about its human: **"Leaves 47 tabs open, calls it research, then asks me to summarize all of it at 2 a.m. Five stars. Would not recommend."**

## Run

```sh
python3 main.py
```

Writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
